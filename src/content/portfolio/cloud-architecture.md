Designed a reusable cloud blueprint with zero-trust networking, layered
observability, and CI/CD guardrails. The design focuses on clear tenant
boundaries, repeatable infrastructure, and production feedback loops.

## Highlights

- Identity-aware access at every service boundary.
- Infrastructure defined and reviewed as code.
- Telemetry built into the baseline, not added after release.
